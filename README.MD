# Tablero Sauber

## Descripción
Este proyecto contiene la estructura del tablero de telemetría y métricas automatizadas de Sauber. Es un entorno web ligero, basado en HTML, diseñado para mostrar información en tiempo real de forma visual y rápida. Actualmente se encuentra desplegado y alojado en la nube mediante GitHub Pages.

## Requisitos Previos
Al ser un proyecto de frontend estático, no requiere instalación de motores ni entornos virtuales complejos. Solo se necesita:
* Un navegador web moderno (Chrome, Edge, Firefox, etc.).
* Un editor de código (como VS Code) para realizar modificaciones.

## Ejecución
Para visualizar el tablero localmente, simplemente basta con abrir el archivo `index.html` directamente en el navegador.
